## 1. 변수

변수는 데이터를 저장하고 필요할 때 다시 사용하기 위한 이름입니다. JavaScript에서는 `let`, `const`를 주로 사용합니다.

```js
let name = "Jane";
name = "John";

console.log(`Hello, ${name}`); // Hello, John

const greeting = "Welcome to the site!";
console.log(`${greeting} ${name}`);
```

- `let`: 값을 다시 할당할 수 있습니다.
- `const`: 선언 후 값을 다시 할당할 수 없습니다.
- 문자열 안에 변수 값을 넣을 때는 템플릿 리터럴과 `${}`를 사용할 수 있습니다.

가능하면 기본값은 `const`로 선언하고, 값이 변경될 때만 `let`을 사용하는 것이 좋습니다.

## 2. 원시 데이터 타입

원시 타입은 하나의 값을 직접 표현하는 데이터 타입입니다.

```js
const number = 10;
console.log(typeof number); // "number"

const bigNumber = 10n;
console.log(typeof bigNumber); // "bigint"

const name = "Jane";
console.log(typeof name); // "string"

const isTrue = true;
console.log(typeof isTrue); // "boolean"

let value;
console.log(typeof value); // "undefined"
```

주요 원시 타입은 다음과 같습니다.

- `number`: 정수와 실수
- `bigint`: 매우 큰 정수
- `string`: 문자열
- `boolean`: `true` 또는 `false`
- `undefined`: 값이 아직 할당되지 않은 상태
- `null`: 값이 없음을 의도적으로 나타내는 값
- `symbol`: 고유한 식별자

`typeof null`의 결과는 역사적인 이유로 `"object"`입니다. 따라서 `null`인지 확인할 때는 `value === null`처럼 비교하는 편이 정확합니다.

## 3. 참조 데이터 타입

배열과 객체는 여러 값을 묶어서 관리할 수 있는 참조 타입입니다.

```js
const numbers = [1, 2, 3, [4, 5]];
console.log(numbers);

const user = {
  name: "Jane",
  age: 30,
};

console.log(user.name);
console.log(user["name"]);
```

객체의 프로퍼티는 점 표기법 또는 대괄호 표기법으로 접근할 수 있습니다.

```js
console.log(user.name);
console.log(user["name"]);
```

대괄호 표기법은 프로퍼티 이름을 변수로 사용할 때 유용합니다.

```js
const property = "age";
console.log(user[property]); // 30
```

참조 타입 변수에는 값 자체가 아니라 값이 저장된 위치에 대한 참조가 담깁니다. 따라서 객체나 배열을 다른 변수에 대입하면 같은 데이터를 가리킬 수 있습니다.

## 4. 연산자와 전개 구문

JavaScript는 값을 계산하고 비교하기 위한 다양한 연산자를 제공합니다.

### 산술 연산자

`+`, `-`, `*`, `/`, `%`, `**`를 사용할 수 있습니다.

```js
console.log(7 + 3); // 10
console.log(7 % 3); // 1
console.log(2 ** 3); // 8
```

`++`, `--`는 값을 1씩 증가하거나 감소시킵니다. 연산자가 앞에 있는지 뒤에 있는지에 따라 반환되는 값이 달라집니다.

```js
let count = 10;
console.log(count++); // 10
console.log(++count); // 12
```

### 비교와 논리 연산자

```js
console.log(10 === 10); // true
console.log(10 !== "10"); // true
console.log(10 > 5 && 3 < 5); // true
console.log(!(10 < 5)); // true
```

`==`보다 타입까지 비교하는 `===`를 사용하는 것이 일반적으로 안전합니다.

### nullish 병합 연산자

`??`는 왼쪽 값이 `null` 또는 `undefined`일 때만 오른쪽 값을 사용합니다.

```js
const firstName = undefined;
const nickname = null;
const defaultName = "Jane";

console.log(firstName ?? nickname ?? defaultName); // Jane
```

빈 문자열이나 숫자 `0`은 `??`에서 유효한 값으로 취급됩니다. 모든 falsy 값을 대체하는 `||`와는 차이가 있습니다.

### 전개 구문

전개 구문 `...`은 배열이나 객체의 값을 펼칠 때 사용합니다.

```js
const first = [1, 2, 3];
const second = [4, 5, 6];
const combined = [...first, ...second];

console.log(combined); // [1, 2, 3, 4, 5, 6]
```

전개 구문을 사용하면 원본 배열을 변경하지 않고 새로운 배열을 만들 수 있습니다.

## 5. 조건문

조건문은 특정 조건에 따라 다른 코드를 실행할 때 사용합니다.

```js
const score = 85;

if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else {
  console.log("C");
}
```

조건이 여러 개일 때는 `else if`를 사용하고, 어떤 조건에도 해당하지 않을 때는 `else`를 사용합니다.

## 6. switch 문

하나의 값을 여러 경우와 비교해야 할 때 `switch` 문을 사용할 수 있습니다.

```js
const day = "월요일";

switch (day) {
  case "월요일":
    console.log("한 주의 시작입니다.");
    break;
  case "금요일":
    console.log("주말이 가까워졌습니다.");
    break;
  default:
    console.log("일반적인 하루입니다.");
}
```

`break`를 생략하면 다음 `case`까지 이어서 실행될 수 있으므로 주의해야 합니다.

## 7. 반복문

반복문은 같은 작업을 여러 번 실행할 때 사용합니다.

### for 문

```js
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

### break와 continue

- `break`: 반복문을 즉시 종료합니다.
- `continue`: 현재 반복만 건너뛰고 다음 반복으로 넘어갑니다.

```js
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;
  }

  console.log(i); // 1, 2, 4, 5
}
```

### for...of 문

배열의 값을 하나씩 꺼낼 때 편리합니다.

```js
for (const number of [1, 2, 3]) {
  console.log(number);
}
```

### while과 do...while

```js
let number = 0;

while (number < 3) {
  console.log(number);
  number++;
}
```

`do...while`은 조건을 나중에 확인하므로 코드 블록이 최소 한 번은 실행됩니다.

## 8. 함수

함수는 특정 작업을 하나의 코드 묶음으로 만들고 필요할 때 호출하는 기능입니다.

```js
function add(x, y) {
  return x + y;
}

console.log(add(5, 3)); // 8
```

함수 선언에서 `x`, `y`는 매개변수이고, 함수를 호출할 때 전달하는 `5`, `3`은 인자입니다.

### 기본 매개변수

```js
function add(x, y = 0) {
  return x + y;
}

console.log(add(5)); // 5
```

`y`에 값을 전달하지 않으면 기본값 `0`이 사용됩니다.

### 나머지 매개변수

전달된 인자를 배열로 모으려면 나머지 매개변수 `...`를 사용합니다.

```js
function sum(...numbers) {
  let result = 0;

  for (const number of numbers) {
    result += number;
  }

  return result;
}

console.log(sum(5, 3, 2)); // 10
```

## 9. 화살표 함수

화살표 함수는 함수를 간결하게 표현하는 문법입니다.

```js
const add = (x, y) => x + y;
const greet = (name) => `Hello, ${name}`;

console.log(add(5, 3)); // 8
console.log(greet("Jane")); // Hello, Jane
```

실행할 코드가 한 줄이고 중괄호를 생략하면 해당 표현식의 결과가 자동으로 반환됩니다.

여러 줄의 코드를 작성하려면 중괄호와 `return`을 사용해야 합니다.

```js
const multiply = (x, y) => {
  const result = x * y;
  return result;
};
```

## 10. 문자열 메서드

문자열은 다양한 내장 메서드를 제공합니다.

```js
const text = "Hello, World! World!";

console.log(text.toUpperCase()); // HELLO, WORLD! WORLD!
console.log(text.toLowerCase()); // hello, world! world!
console.log(text.includes("World")); // true
console.log(text.startsWith("Hello")); // true
console.log(text.indexOf("World")); // 7
console.log(text.replace("World", "JavaScript"));
console.log(text.replaceAll("World", "JavaScript"));
```

공백을 제거하거나 문자열을 잘라낼 수도 있습니다.

```js
const value = "   JavaScript   ";

console.log(value.trim());
console.log(value.trimStart());
console.log(value.trimEnd());
console.log("repeat".repeat(3));
console.log("Hello, World".split(", ")); // ["Hello", "World"]
```

`slice(start, end)`와 `substring(start, end)` 모두 문자열 일부를 반환하지만, 음수 인덱스를 사용할 수 있는지 등 세부 동작에 차이가 있습니다.

## 11. 배열 메서드

배열에는 값을 추가, 삭제, 탐색, 변환하는 메서드가 있습니다.

```js
const numbers = [1, 2, 3, 4, 5];

numbers.push(6); // 마지막에 추가
numbers.pop(); // 마지막 요소 제거
numbers.unshift(0); // 처음에 추가
numbers.shift(); // 첫 요소 제거
```

### 배열 순회와 변환

```js
numbers.forEach((number, index) => {
  console.log(`${index}: ${number}`);
});

const doubled = numbers.map((number) => number * 2);
const larger = numbers.filter((number) => number > 3);

console.log(doubled); // [2, 4, 6, 8, 10]
console.log(larger); // [4, 5]
```

- `forEach`: 배열을 순회하지만 새로운 배열을 반환하지 않습니다.
- `map`: 각 요소를 변환한 새로운 배열을 반환합니다.
- `filter`: 조건에 맞는 요소만 모은 새로운 배열을 반환합니다.

### 검색과 집계

```js
console.log(numbers.includes(3)); // true
console.log(numbers.find((number) => number > 3)); // 4
console.log(numbers.findIndex((number) => number > 3)); // 3
console.log(numbers.reduce((sum, number) => sum + number, 0)); // 15
```

`reduce`는 배열의 값을 하나의 결과로 합칠 때 유용합니다.

### 배열 자르기와 합치기

```js
const part = numbers.slice(1, 4);
const joined = numbers.concat([6, 7]);
const text = numbers.join(":");

console.log(part); // [2, 3, 4]
console.log(joined); // [1, 2, 3, 4, 5, 6, 7]
console.log(text); // 1:2:3:4:5
```

`slice`는 원본 배열을 변경하지 않지만, `splice`는 원본 배열을 직접 변경합니다. 배열을 안전하게 복사하거나 일부만 사용할 때는 이 차이를 기억해야 합니다.

## 12. 객체 심화

객체의 프로퍼티에 함수를 저장하면 메서드가 됩니다.

```js
const user = {
  name: "ilyoung",
  country: "korea",
  greeting() {
    console.log("hi");
  },
};

user.greeting();
```

객체의 키와 값을 배열로 가져올 때는 `Object`의 정적 메서드를 사용합니다.

```js
console.log(Object.keys(user));
console.log(Object.values(user));
console.log(Object.entries(user));
```

배열인지 확인하려면 `Array.isArray`를 사용합니다.

```js
console.log(Array.isArray(user)); // false
console.log(Array.isArray([1, 2, 3])); // true
```

## 13. 구조 분해 할당

구조 분해 할당은 배열이나 객체에서 필요한 값을 꺼내 변수에 저장하는 문법입니다.

### 배열 구조 분해

```js
const numbers = [1, 2, 3, 4, 5];
const [one, two, three] = numbers;
const [first, , third] = numbers;
const [head, ...others] = numbers;

console.log(head); // 1
console.log(others); // [2, 3, 4, 5]
```

### 객체 구조 분해

```js
const point = { x: 100, y: 200 };
const { x, y } = point;
const { x: newX, y: newY } = point;
```

프로퍼티 이름과 다른 변수명을 사용하려면 `프로퍼티명: 변수명` 형태로 작성합니다.

함수 매개변수에서도 구조 분해 할당을 사용할 수 있습니다.

```js
const sum = ({ x, y }) => x + y;

console.log(sum(point)); // 300
```

두 변수의 값을 교환할 때도 활용할 수 있습니다.

```js
let a = 100;
let b = 200;

[a, b] = [b, a];
```

## 14. DOM 조작

DOM(Document Object Model)은 HTML 문서를 JavaScript 객체 구조로 표현한 것입니다. JavaScript를 이용하면 HTML 요소를 찾고, 내용을 변경하고, 스타일을 적용할 수 있습니다.

```js
const title = document.querySelector("h2");

title.innerText = "안녕 세상아";
title.style.color = "blue";
```

요소를 찾는 대표적인 방법은 다음과 같습니다.

```js
document.getElementById("preface");
document.getElementsByClassName("preface_class");
document.getElementsByTagName("h2");
document.querySelector(".preface_class");
document.querySelectorAll(".preface_class");
```

- `querySelector`: 조건에 맞는 첫 번째 요소를 반환합니다.
- `querySelectorAll`: 조건에 맞는 모든 요소를 반환합니다.

새로운 요소를 만들어 문서에 추가할 수도 있습니다.

```js
const heading = document.createElement("h1");
heading.innerText = "새로운 제목";

document.body.appendChild(heading);
```

## 15. 이벤트

이벤트는 사용자의 클릭, 입력, 키보드 조작처럼 웹 페이지에서 발생하는 동작입니다.

```js
function handleClick(event) {
  console.log(event);
}

const button = document.querySelector("button");
button.addEventListener("click", handleClick);
```

이벤트 리스너를 제거하려면 같은 함수를 전달해야 합니다.

```js
button.removeEventListener("click", handleClick);
```

따라서 이벤트를 제거해야 하는 경우에는 다음처럼 익명 함수를 직접 전달하기보다 함수 이름을 별도로 관리하는 편이 좋습니다.

```js
function removeClickEvent() {
  button.removeEventListener("click", handleClick);
}
```

## 16. 모듈

JavaScript 파일을 모듈로 사용하려면 HTML의 `script` 태그에 `type="module"`을 지정합니다.

```html
<script type="module" src="./index.js" defer></script>
```

### named export와 import

```js
// hello.js
export const greeting = () => {
  console.log("Hello");
};

// index.js
import { greeting } from "./hello.js";
greeting();
```

### default export와 import

```js
// hello.js
export default function hello() {
  console.log("Hello");
}

// index.js
import hello from "./hello.js";
hello();
```

named export는 중괄호 안에 내보낸 이름을 정확히 작성해야 하고, default export는 원하는 이름으로 가져올 수 있습니다.

## 17. 모달 창 만들기

`index.js`의 마지막 부분에서는 버튼을 눌렀을 때 모달을 열고 닫는 기능을 구현합니다.

```js
const openButton = document.querySelector(".open");
const container = document.querySelector(".container");
const closeButton = document.querySelector(".close");

openButton.addEventListener("click", () => {
  container.style.display = "flex";
  openButton.style.display = "none";
});

closeButton.addEventListener("click", () => {
  container.style.display = "none";
  openButton.style.display = "block";
});
```

모달 바깥 영역을 클릭했을 때 닫히게 하려면 이벤트 객체의 `target`을 확인합니다.

```js
container.addEventListener("click", (event) => {
  if (event.target === container) {
    container.style.display = "none";
    openButton.style.display = "block";
  }
});
```

`event.target`은 실제로 클릭된 요소이고, `container`와 같을 때는 내부 콘텐츠가 아닌 배경 영역을 클릭한 경우입니다.

실제 프로젝트에서는 `style.display`를 직접 바꾸는 대신 CSS 클래스를 추가하고 제거하는 방식도 많이 사용합니다.

```js
container.classList.add("is-open");
container.classList.remove("is-open");
```

## 마무리

이번 학습에서는 JavaScript의 기본 문법부터 브라우저 화면을 조작하는 방법까지 살펴보았습니다.

핵심 내용을 정리하면 다음과 같습니다.

1. `const`와 `let`으로 변수를 선언합니다.
2. 원시 타입과 참조 타입의 차이를 이해합니다.
3. 조건문과 반복문으로 실행 흐름을 제어합니다.
4. 함수와 화살표 함수로 코드를 재사용합니다.
5. 문자열과 배열 메서드로 데이터를 다룹니다.
6. 구조 분해 할당과 전개 구문으로 코드를 간결하게 작성합니다.
7. DOM과 이벤트를 이용해 웹 페이지와 상호작용합니다.
8. 모듈로 JavaScript 코드를 여러 파일에 나누어 관리합니다.

문법을 외우는 것보다 작은 예제를 직접 실행하고, 값을 바꿔 결과를 확인하는 과정이 중요합니다. 다음 단계에서는 비동기 처리, `fetch`, 클래스, 예외 처리 등을 학습하면 더 다양한 웹 기능을 만들 수 있습니다.
