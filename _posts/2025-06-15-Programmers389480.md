## <a href="https://school.programmers.co.kr/learn/courses/30/lessons/389480" target="_blank">완전범죄</a>

```cpp
#include <string>
#include <vector>
#include <unordered_set>
using namespace std;

unordered_set<string> st; 
int ans,m;

void dfs(vector<vector<int>>& vv, int idx, int a, int b)
{
    if(idx == vv.size()) {
        ans = min(ans, a);
        return;
    }
    
    //pruning 
    auto [it,succ] = st.emplace(to_string(idx) + " " + to_string(a) + " " + to_string(b));
    if(!succ)
        return;
    
    int na = a + vv[idx][0];
    int nb = b + vv[idx][1];
    
    if(na < ans) //ans 값만 비교하면 됨
        dfs(vv, idx+1, na, b);
    
    if(nb < m)
        dfs(vv, idx+1, a, nb);
}

int solution(vector<vector<int>> info, int a, int b)
{
    ans = a; //ans 값이 n 값이 넘을수 없으므로 초기값을 n으로 설정 
    m = b;
    st.clear();
    dfs(info,0,0,0);
    return ans == a ? -1 : ans;
}
```

### 제한 사항

- 1 ≤ info의 길이 ≤ 40
- 1 ≤ n ≤ 120
- 1 ≤ m ≤ 120

### 풀이

- 완전탐색을 할 경우 O(2^n) = O(2^40) = 10^12로 시간초과
- pruning
  - n, m 값이 넘을 경우 더 이상 탐색하지 않음
  - 수많은 가지 중에 같은 idx에 들어온 a, b 값이 같은 경우가 있다면 그 뒤의 결과는 동일하므로 탐색하지 않음

### 시간복잡도

- 각각의 인덱스당 a, b 값의 조합은 n × m 이므로 O(info.size() × n × m) = O(40 × 120 × 120) = O(576000)

### DP 알고리즘

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int solution(vector<vector<int>> info, int n, int m)
{
    int row = info.size();
    int col = m; //m 이상은 문제가 성립되지 않으므로 계산할 필요가 없음
    vector<vector<int>> dp(row+1, vector<int>(col,n)); //n은 정의되지 않았다는 의미
    dp[0][0] = 0; // item을 선택하지 않았을 때 b와 a의 흔적은 0 이라는 의미
    
    for(int i=1; i<=row; ++i)
    {
        int a = info[i-1][0];
        int b = info[i-1][1];
        for(int j=0; j<col; ++j)
        {
            //a를 선택하는 경우
            dp[i][j] = min(dp[i][j], dp[i-1][j] + a);             
            
            //b를 선택하는 경우
            if(j+b < col)
                dp[i][j+b] = min(dp[i][j+b], dp[i-1][j]);             
        }
    }
    
    int ans = *min_element(dp[row].begin(), dp[row].end());
    return ans < n ? ans : -1;
}
```

### DP 풀이

- dp(i,j) : i번째 아이템을 선택하고 b의 흔적이 j일 때 a의 흔적의 최소값
- a를 선택하는 경우 : 현재 값 = min(현재 값, 위의 값 + a)
- b를 선택하는 경우 : 현재 포지션에서 b를 더한 위치의 값 = min(현재 포지션에서 b를 더한 위치의 값, 위의 값)
- 백준의 배낭 문제 참고
