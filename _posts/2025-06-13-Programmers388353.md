## <a href="https://school.programmers.co.kr/learn/courses/30/lessons/388353" target="_blank">지게차와 크레인</a>

```cpp
int row, col;
int dx[] = {0,0,-1,1}, dy[] = {-1,1,0,0};

int crane(vector<string>& mat, char target)
{
    int delCnt = 0;
    for(int i=0; i<row; ++i)
        for(int j=0; j<col; ++j)
            if(mat[i][j] == target)
                mat[i][j] = '2', ++delCnt;
    return delCnt;
}

int forklift(vector<string>& mat, char target)
{
    int delCnt = 0;
    vector<vector<bool>> visit(row,vector<bool>(col,false));
    queue<pair<int,int>> q;
    q.emplace(0,0);
    visit[0][0] = true;

    while(!q.empty())
    {
        auto [x,y] = q.front(); q.pop();
        for(int i=0; i<4; ++i)
        {
            int nx = x + dx[i], ny = y + dy[i];
            if(nx<0 || ny<0 || nx==row || ny==col || visit[nx][ny])
                continue;
            
            // 이 좌표가 나중에 걸리더라도 visit를 true로 했기 때문에 바로 위 로직에서 continue 됨
            // 그래서 mat[nx][ny] = '1'로 했더라도 로직상 이 좌표를 경유해서 지나갈수 없음 
            if(mat[nx][ny] == target) {
                mat[nx][ny] = '1', visit[nx][ny] = true, ++delCnt;
                continue;                
            }
            
            if(mat[nx][ny] == '1' || mat[nx][ny] == '2')
                mat[nx][ny] = '1', visit[nx][ny] = true, q.emplace(nx,ny);
        }
    }
    return delCnt;
}

int solution(vector<string> storage, vector<string> requests)
{
    row = storage.size() + 2;
    col = storage[0].size() + 2;
    vector<string> mat(row, string(col,'1'));
    for(int i=1; i<row-1; ++i)
        for(int j=1; j<col-1; ++j)
            mat[i][j] = storage[i-1][j-1];
    
    int delCnt = 0;
    for(string& req : requests)
    {
        if(req.size() == 1)
            delCnt += forklift(mat, req[0]);
        else
            delCnt += crane(mat, req[0]);
    }
    return (row-2)*(col-2) - delCnt;
}
```

### 제한 사항

- 2 ≤ storage의 길이 = n ≤ 50
- 2 ≤ storage[i]의 길이 = m ≤ 50
- 1 ≤ requests의 길이 ≤ 100

### 풀이

- 최적화부터 생각하다가 풀이가 복잡해지고 시간초과 남
  - unordered_map에 좌표를 저장해서 처리하는 방식이 좋을것 같지만 구현해보니 너무 복잡해짐
  - 다른 사람의 풀이를 참고하여 완전히 새로 구현
- 풀이의 핵심은 req 하나당 BFS 한번으로 가능한 모든 block 처리 (처음에는 좌표 하나당 BFS 적용하니 시간초과)
- 지게차로 빼낸 block은 1로 바꾸고, 크레인으로 빼낸 block은 2로 하나의 matrix에서 처리
  - 완성된 코드를 보니, 로직상 굳이 1,2로 나누지 않고, 0으로 통일해도 됨
- 일단 storage를 1로 둘러싸고, BFS는 무조건 0,0 좌표에서 시작

### 시간복잡도

- BFS의 시간복잡도는 O(V + E) = 노드 수 + 총간선의 수 = (50 × 50) + (50 × 50 × 4) = O(12500)
- requests(100) × BFS = O(1250000) = O(10^6)
- O(10^8) = 1초 이하로 충분히 가능

### 참고

- q.push({x,y})는 임시객체를 만들어 복사하는 것이므로, q.emplace(x,y)로 직접 생성하는 것이 더 빠름
